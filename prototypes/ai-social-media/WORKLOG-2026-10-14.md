### 1-1. Top 목록 → 상세
- **Top Performing Content** 행 → 광고 상세 `campaign.html?id=…` (Promoted Content)
  - Top Performing 데이터는 이제 광고 표(`META_CAMPAIGNS_MOCK`)에서 나옴 → 제목·수치가 Meta Ads Performance 표와 일치.
  - `buildPosts()`가 기간 안에 집행된 광고를 해당 플랫폼 게시물에 붙여 Paid로 표시 (spend / leads / CPL = 기간 내 합계).
  - Reach 목표 광고는 leads 0, CPL "—".
- **Top Organic Posts** 행 → 새 **게시물 상세 `post.html?id=…&period=…`**
- **Post Performance** 게시물 제목도 링크 (organic → post.html, paid → campaign.html). 검정 제목, hover 시 밑줄.

### 1-2. 새 페이지 `v2/post.html` (Organic 게시물 상세)
- 구조는 광고 상세(campaign.html)와 동일: 제목 + 메타(Organic · 게시일 · 플랫폼 · 유형) + Export → 표 1행(Views · Likes · Comments · Engagement) → **Performance Over Time**(Views / Likes / Comments / Engagement rate 탭, Daily/Weekly/Monthly) → **Post** 카드(Open in Library →).
- 일별 데이터: `postDaily(post)` (analytics-shared.js) — 게시 직후 몰리고 점점 줄어드는 형태, 합계는 표 숫자와 일치.
- paid 게시물 id로 들어오면 campaign.html로 자동 이동.
- 브레드크럼 Post Performance → 목록으로 돌아가며 해당 행 하이라이트(`?post=<id>`).

### 1-3. 상세 페이지 기간 선택 (post.html, campaign.html)
- 상단에 30 days / 90 days / All time / Custom (Analytics와 같은 Segment Chip + Date Picker).
- 이전 화면 기간이 자동 선택 (`?period=`). Lifetime 목록(Meta Ads 표, Promoted Content 목록)에서 오면 `range=all` → All time.
- 표 1행 · 그래프 · Export가 선택 기간을 따름. All time = Lifetime.
- 광고의 Impressions / Reach는 기간 선택 시 지출 비율로 나눈 근사치 (Meta API 연결 시 실제 값으로 교체).
- 공용 헬퍼: `detailSpan()`, `bindDetailPeriod()` (analytics-shared.js), `mountAdsTable({ rowData })` 옵션 추가.

### 1-4. Post Performance
- "Published: All" 드롭다운 칩 삭제, 그래프 클릭 필터 삭제.
- Analytics 막대 클릭 → `?period=custom&from&to&base=<원래 기간>` 으로 열림. `base` 덕분에 막대 숫자 = 목록 개수.
  - 헬퍼: `readBasePeriod()`, `baseParams()`, `postsFor()`, `setCustomRange(start, end, key)` (두 번째 슬롯 `PERIODS.base`).
  - 예전 `?bucket=` 링크도 같은 방식으로 자동 변환.
