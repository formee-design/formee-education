Figma's "01 Icons" library (3191:30848) — the full 151-icon set across 20 categories, downloaded and organized to match Figma's own "icon library — by category" grouping. Each is exported as-is from Figma (baked-in color, not currentColor), so a spot that needs the icon to recolor on state still needs its own treatment. A handful of the earliest additions also carry the emoji/hand-drawn glyph they replaced, from before this page covered the full set.
